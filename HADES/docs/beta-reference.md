# HADES BETA visual reference — PRIMUS

The BETA interface is a visual prototype of the **HADES PRIMUS** concept
(chat-primary command deck). Classic and Obsidian remain separate product GUIs.

## Concept

Reference mock: `docs/design/hades-primus-reference.png`

- Deep navy / charcoal shell with gold, emerald and steel accents
- Chat-first home: composer, module tiles (Taken / Research / Trading / Energie), Twin Focus
- Right rail: Sessiemodel, Liquiditeit, Memory Hits, Plugin Status (mockdata)
- Spirituality / divinity expressed as restraint, light and serif brand — not costume
- Twin Focus = professional dual reading (Helder / Schaduw), not clinical metaphor

## Contract

- `1672 × 941` remains the canonical composition size.
- The complete canvas scales proportionally as one unit; page geometry must not independently reflow.
- Classic and Obsidian are not restyled by the BETA / PRIMUS layer.
- BETA pages are visual-first. Controls may be non-functional until product wiring lands page by page.
- Chat has two states: dashboard (PRIMUS home) and conversation detail.
- Extra workspace pages stay reachable under **Meer** and keep existing mock layouts inside the PRIMUS chrome.

Styles: legacy BETA + pixel-reference layers, then `primus-reference.css` last.

Paste a compact update into `docs/CURRENT_STATUS.md` or a dated worklog before switching from Cursor to Astra/another agent.

```md
## Latest development handoff

Date:
Branch:
Commit:
Subsystem:

### Goal
- ...

### Changed
- file/path: what and why

### Verified
- command: result
- command: result

### Not verified / environment limitation
- ...

### Known issues
- ...

### Next exact action
1. ...
2. ...

### Do not regress
- ...
```

Keep this factual. Do not paste entire chat transcripts or hidden reasoning. The repository plus tests are the source of truth.
